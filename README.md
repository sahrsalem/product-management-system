# Product Management System

A simple project for managing products. It provides an interface to add, update, and delete products, with automatic calculation of the total price.

---

## 🔗 Live Demo
Check out the project here:  
[Product Management System](https://sahrsalem.github.io/product-management-system/)

---

## 🎨 Visual Identity
- **Purple**: depth and philosophical spirit  
- **Sky Blue**: clarity and calmness  
- **Pink**: human warmth  
- **Black & White**: balance and professionalism  

These colors were blended to give the project a unique soul and lively identity.

---

## ⚙️ Features
- Add new products with details (price, tax, discount).  
- Update product information.  
- Delete products easily.  
- Automatic total price calculation.  
- Simple and user-friendly interface.

---

## 📂 Files
- `index.html` → project interface  
- `style.css` → design and colors  
- `main.js` → product management logic
